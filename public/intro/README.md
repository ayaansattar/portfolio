# Intro video

Drop your generated CRT clip here:

- `crt-enter.mp4` (required for the video intro)
- `crt-enter.webm` (optional)

Boot sequence: **CRT video → name letter intro → site**.

Keep the clip short (**3–5s** ideal). End on a frame that matches the dark name intro (or a near-black glow) so the handoff into the letter animation reads cleanly.

If the file is missing, playback fails, or `prefers-reduced-motion` is on, the site skips straight to the letter intro (or a short reduced-motion beat).
